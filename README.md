# Імітаційне моделювання методики верифікації OSINT-даних

Код до статті: В'юнник Ю. Д., Мальцев В. В. «Методика верифікації OSINT-даних з урахуванням залежності джерел під час виявлення фішингових кампаній» (журнал «Кібербезпека: освіта, наука, техніка»).

Скрипт відтворює таблицю 5 і рис. 2 статті: порівнює три підходи до оцінювання фішингових індикаторів (А – голосування більшістю, Б – зважене агрегування без групування, В – запропонована методика) у моделі, де частина OSINT-джерел є агрегаторами, що копіюють записи інших джерел.

## Вимоги

- Python 3.9 або новіший
- бібліотеки `numpy` і `matplotlib` (встановлюються командою нижче)
- для рис. 1 (необов'язково) – програма Graphviz

## Встановлення

```
pip install -r requirements.txt
```

## Запуск

| Команда | Що робить | Час |
|---|---|---|
| `python osint_sim.py --quick` | швидка перевірка, що все працює (5 повторень; числа трохи відрізняються від статті) | ~5 с |
| `python osint_sim.py` | повний розрахунок, числа збігаються зі статтею | ~40 с – 2 хв |
| `python osint_sim.py --extra` | те саме + додаткові перевірки (частка фішингу 20 % і 60 %, мінімум 3 групи) | ~1–3 хв |
| `python figures.py` | будує рис. 2 (`fig2.png`) з файлу `results.json` | ~3 с |
| `dot -Tpng -Gdpi=300 fig1.dot -o fig1.png` | будує рис. 1 (потрібен Graphviz) | ~1 с |

На Linux і macOS замість `python` може знадобитися `python3`.

## Результати

- `results.json` – усі обчислені показники (середнє та стандартне відхилення за повтореннями);
- у консоль виводяться таблиця 5, дані для рис. 2а і 2б та середня кількість повідомлень на індикатор;
- `fig2.png` – рис. 2 статті.

Генератор випадкових чисел має фіксовані зерна (`seed=2026`), тому повторний запуск дає ті самі числа.

## Параметри моделі

Усі параметри задано на початку `osint_sim.py`:

- `PRIMARY` – первинні джерела (покриття, точність, чи публікують спростування, середня вага) – табл. 3 статті;
- `PARENT_P` – імовірність, що агрегатор віддзеркалює те чи інше первинне джерело;
- `COPY_P` – частка записів, які копіює агрегатор (0,8);
- `COPY_W` – діапазон ваги, яку аналітик приписує агрегатору (0,50–0,75);
- `PREV` – частка фішингових індикаторів (0,4);
- `TH_S`, `TH_VETO`, `MIN_GROUPS` – пороги правила рішення (0,6; 0,7; 2).

Значення параметрів є модельними припущеннями, а не емпіричними оцінками (див. розділ «Методика дослідження» статті).
